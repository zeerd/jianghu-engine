# 命名规范

本规范适用于**所有新增代码**与**任何被修改的符号**。
在存量代码中碰到旧风格时，**不要**为了"和周围旧代码保持一致"而沿用错误风格——改到哪个符号，就把那个符号改对。


---

## 1. C++ 标识符

**总则**：类型（类 / 结构体 / 接口 / 枚举 / 类型别名）用 `PascalCase`；函数、方法、变量、参数一律
`snake_case`；编译期常量与宏用 `UPPER_SNAKE`；带前缀的族（`m_`/`s_`/`g_`/`l_`）在前缀之后接 `snake_case`。
任何名字都不得混用两种风格；逐类的例外与细分约定见下表。

| 类别 | 规则 |
|:---|:---|
| 类 / 结构体 | `PascalCase`；**类**带 `C` 前缀，**struct 不带前缀** |
| 接口 | `I` + `PascalCase` |
| 模板包装类 | `C` + 基类名 + `T` |
| 枚举类型 | `PascalCase`；优先 `enum class` |
| 枚举成员（`enum class`，纯 C++ 内部） | `PascalCase`（限定名天然消歧） |
| 枚举成员（传统 `enum`，值泄漏到外层作用域） | `UPPER_SNAKE` |
| 枚举成员（暴露给 Lua） | `UPPER_SNAKE`；名字是 Lua 脚本按字符串引用的**协议，不可改** |
| 方法 / 自由函数 | **`snake_case`**（唯一风格，禁止 PascalCase 与混合） |
| Lua C 闭包 | `l_` + `snake_case`（**例外**，固定前缀） |
| 成员变量 | `m_` + `snake_case`，**禁止类型前缀字母** |
| 静态成员 | `s_` + `snake_case` |
| 全局变量 | `g_` + `snake_case`（**唯一**全局前缀，禁用 `sys_` 与裸名） |
| 形参 / 局部变量 | `snake_case`，**禁止 `n`/`p`/`l`/`b`/`f`/`x` 等匈牙利前缀** |
| 常量 / 宏 | `UPPER_SNAKE`，禁止前导下划线 |
| 类型别名 `typedef` | `PascalCase` |

**语义前缀（推荐，非强制）**：布尔查询用 `is_`/`can_`/`has_`；dbase 读写用 `query_`/`set_`/`del_`；生命周期回调用 `on_`。

**参数顺序**：函数参数中同时存在输入参数与输出参数时，**输入在前、输出在后**。

**单例访问器宏**：单例访问器宏（如 `#define g_Engine CEngine::instance()`）刻意保持 `g_` + PascalCase 形态，不改为 `UPPER_SNAKE`。

### 命名冲突与双 API 处理

- **多对一合并**禁用同名同签名（会重复定义），用 `_impl` 后缀区分。
- **大小写双 API**：同一类里若出现仅大小写不同的两个名字，必须合并到 `snake_case` 的那一个、重载靠签名区分；同继承链不同语义**不可合并**——必须靠语义区分名分开，合并成同名会触发 C++ 名字隐藏、静默破坏多态。
- **成员名隐藏同名自由函数**：成员体内调用自由函数需全局限定 `::func(...)`。
- **参数顺序相反的重载**必须改用语义区分名，禁止只靠参数顺序区分调用。
- **`l_` 前缀是 Lua C 闭包专用约定**，成员方法不得 snake 成 `l_xxx`，改用语义化名称（如 `save_local`）。
- **Win32/第三方 API 镜像名保持原样**，不 snake 化。

## 2. 文件名与目录

| 规则 | 说明 |
|:---|:---|
| 文件 | `PascalCase`，且**与文件内主类同名去掉 `C` 前缀** |
| 主类判定 | 一个 `.h` 只应有**一个**主类；辅助类/struct 跟随主类文件，不再单独成文 |
| 头/源配对 | `Foo.h` ↔ `Foo.cpp`；一个 `.h` 的实现可拆到 `FooBar.cpp`、`FooBaz.cpp`（按职责），但**首字母段必须与头文件一致** |
| 测试文件 | `test_<被测模块>.cpp`，保持 `snake_case`（Google Test 约定，属规范的一部分） |
| 目录 | 全小写 `snake_case` |

## 3. Lua 脚本

Lua 侧统一使用 `snake_case`。本节是对该约定的**固化**，同样只约束新增与被修改的脚本，不做存量风格迁移。

| 类别 | 规则 |
|:---|:---|
| 文件 / 模块名 | `snake_case`，与对象 `base_name` 一致 |
| 函数 | `snake_case` |
| 模块表 | 固定用 `M`（工具/公共模块）或对象类型名 |
| 局部变量 | `snake_case` |
| 常量 | `UPPER_SNAKE` |
| 私有 | 前导 `_`，不导出到模块外 |

**禁止**：Lua 里出现 PascalCase 或 camelCase 函数名。

**对象脚本文件名**：对象脚本的文件名即游戏数据键（房间/NPC/物品加载名、存档引用），**必须**与脚本声明的 `base_name` 一致且为 `snake_case`。纯库模块由 `require` 引入、不作数据键，同样须 `snake_case`。

**绑定键同名函数**：Lua 中与 C++ 绑定表键同名的函数保持原名。
