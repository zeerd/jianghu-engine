# Triger 部分语法与字段规范


## 文件骨架（只写 Triger 时）

```ini
[Setting]
TrigerSetNum=100          ; 分区总数上限，必须 ≥ 实际 TrigerSet 编号
TrigerShareNum=100        ; Share 触发上限，本脚本不用可照填
Name=$Name
ID=$ID

[TrigerSet_1]
KEY=进入本分区要匹配的文字
TrigerNum=100             ; 本分区触发条数上限（预留槽位，非实际条数），惯例 100

[Triger1_1]
Msg=匹配到的第一条服务器文字
Cmd=要发送的命令1;要发送的命令2;
Obj=命令1的目标;命令2的目标;
Tmr=500                   ; 延迟毫秒
Tlp=1                     ; 可选，关键交互步骤标记（沿用范例惯例）
```

其余节（`[PreCmd]`、`[Seek]`、`[Share_n]`、`[Enemys]`、`[QuickButton_n]`）留空占位即可。

## 分区机制

- `KEY=` 命中某条屏幕文字 → 该 `TrigerSet_N` 分区被激活，组内 `[TrigerN_M]` 的 `Msg` 开始生效。
- 分区之间靠 **`Cmd` 里的 `!set 变量 值` 产生新回显**（`你设置环境变量：X 为 Y。`）去命中下一个分区的 `KEY`，形成状态机；或用 `@goto(TrigerN_M)` 直接跳转。
- `@LastSet` 回上一个分区；分区是第一个时变为"未触发任何分区"状态。
- `KEY`/`Msg` 同为匹配表达式：支持 `*` 通配、`|` 多选一；行首加 `R` 表示纯正则（不解析 `*?` 通配）。**正则特殊字符 `(` `)` `[` `.` 等在非 R 模式下按字面处理，但用 R 时必须转义。**

## 字段

| 字段 | 说明 |
|---|---|
| `KEY` | 激活本分区的匹配文字，如 `KEY=百晓生:你去帮我把*杀了吧！` |
| `TrigerNum` | 分区触发条数上限（预留），必须 ≥ 组内实际条数 |
| `Msg` | 触发匹配文字，`*` 通配、`|` 多选一，行首 `R` 纯正则 |
| `Cmd` | 分号分隔的命令序列，与 `Obj` 按分号位置一一对应 |
| `Obj` | 每条命令的目标，按 `;` 对齐；可为空（连续 `;;`） |
| `Tmr` | 毫秒。命令发送间隔；`0` = 立即执行但可被打断。低于 666 的出售类动作会被按 666 处理 |
| `Tlp` | 范例中 824 处均为 `Tlp=1`，出现在与 NPC 交互（`/ask`、`!Give`、`/kill` 收尾）的步骤上；沿用即可 |

## 常用命令

| 命令 | 格式 | 示例 |
|---|---|---|
| `!go` | `!go 房间名`（自动寻路，需登录文件定义寻路文件） | `!go 成都锦城驿` |
| `!go>` | 同上，屏蔽时空等公共出口（没 mp 时用） | `!go>梅庄小筑` |
| `!t` | `!t 名字或id,命令;其他;`，能选到就执行并忽略后续 | `!t bai xiao sheng,/ask wen;` |
| `/ask` | `/ask 参数`，参数对应 NPC `add_menu_item` 的第二参数 | `/ask y`、`/askquest` |
| `/kill` | 攻击目标 | `Obj=-*卓一行*` |
| `!Give` | `!Give 物品名,数量` | `!Give 绝情丹;` |
| `!if` | `!if 表达式,命令;假则执行后面;`，支持 `== != > >= < <= && \|\|` | `!if [count(绝情丹)]>0,!t guo er,!Give 绝情丹;` |
| `!has`/`!no` | `!has 表达式\|数量,命令;` 身上/场景有无物品 | `!has 战斗场景,/flee;!go X;` |
| `!set`/`!sset` | 设变量（后者静默），回显可被 KEY 捕获 | `!set 古墓任务 百晓生` |
| `!where` | 重新显示"你进入了xx"，用于丢状态后重新定位 | `Cmd=!where;` |
| `!c`/`!cast` | 施法 | `!c recover` |
| `#n` | 暂停 n 毫秒 | `#350;` |
| `@goto` | `@goto(Triger5_2)` 跳转触发 | 见上 |

## 目标对象（Obj=）

| 写法 | 含义 |
|---|---|
| 空 | 无需目标 |
| `zhun yi hang` | 直接指定 id（`set_name` 第二参数，含空格） |
| `$ID` | 自己 |
| `@1`~`@n` | 场景列表第 1~n 项 |
| `--` / `-=` | Enemys 列表正向/反向查找 |
| `@@` | Goods 列表 |
| `@E` | Fight_room 列表 |
| `#1`~`#4` | 战斗对面战队第 n 人；`#5`~`#8` 本方队友 |
| `-表达式` | 按表达式在场景中找，找不到则不发命令 |

**Cmd 与 Obj 分号必须对齐**：`Cmd=a;b;` 对应 `Obj=x;;`（第二条无目标）。

## 匹配文字（Msg/KEY）写法要点

- 服务器显示 NPC 说话为 **`中文名:台词`**（如 `江湖郎中:好了，再睡一觉吧！`）；`say()` 文本自带"百晓生说："时显示为 `百晓生:百晓生说：…`。Msg 必须与实际输出一字不差，可变部分用 `*`。
- 变量部分（人名、数字、地名）一律换 `*`：`你获得了*点经验`、`找不到从此处到*的路径`。
- 中文标点（`：`、`，`、`！`）与英文标点不可混用，以服务器实际输出为准。
- 单行 ≤ 512 字符；超长的用 `|` 拆成多条 Msg 或拆多个触发。

## 兜底触发（建议常驻）

```ini
[TrigerN_x] Msg=你的动作还没有完成，不能移动。            Cmd=!where;      Tmr=600
[TrigerN_y] Msg=找不到从此处到*的路径。                    Cmd=/trans 1;    Tmr=500   ; 换交通方式后重试 !go
[TrigerN_z] Msg=你重新连线进入这个世界。|你要往哪个方向走？ Cmd=!where;      Tmr=500
```

## 编码

范例脚本均为 **GBK**；数据集为 UTF-8。生成的 ini 必须保存为 GBK（见 SKILL.md 转码命令），否则客户端显示乱码。
