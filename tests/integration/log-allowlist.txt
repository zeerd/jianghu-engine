# 登记规则（新增负测/预期服务端报错时必须同步登记，见集成测试指令 §4.5）：
#   每行：签名<TAB>归属场景/理由（TAB 分隔）；# 起头为注释。
#   签名对「去掉 [LEVEL] (时间戳) 前缀后的消息体」做子串匹配——
#   必须锚定变量部分（wrongpass、house_ 等），使其只命中预期类、
#   不遮蔽同类中的真异常（真丢档/真 DB 故障带不同变量值，照常 FAIL）。
#   签名本身锚不到变量时（口令已掩码的认证失败即此例），条目里必须写明同类
#   真异常改由哪条通道兜底——整类吸收静音的正是那部分真故障。
# 未登记的 ERROR/FATAL 一律判整轮 FAIL；WARN 不走本表（只计数入报告）。
#
